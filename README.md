# 식혜 주문 자동계산기 PRO v7

UI 품질을 높이고, 무료배송 안내형 문구를 추가한 버전입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## v7 반영 사항

- 상단 히어로 영역을 일러스트형 대시보드 스타일로 업그레이드
- 수량 버튼 `-`, `+`, `+5`, `0` 글자 크기 확대 및 굵게 처리
- 택배비 OFF 시 `4. 무료배송 안내형` 문구 자동 추가
- 무료배송 안내형에는 `택배비 = 0원` 및 `택배비는 업체에서 부담합니다.` 문구 포함
- 왼쪽 세로형 수량 버튼 계산기 / 오른쪽 총합계 카드 구조 유지
- 카톡 문구 자동 인식, 입금 안내형, CSV/TXT 다운로드 유지
