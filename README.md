# 식혜 주문 자동계산기 PRO v17

기존 v16의 수량 계산, 카톡 주문 인식, 택배비 기본 OFF, 할인, 입금계좌, 고객 문구 복사 기능을 유지합니다.

## v17 추가 기능: 그림으로 보는 사용설명서

- **화면 맨 위 오른쪽 `❔ 사용설명서` 버튼**을 누르면 설명서가 팝업으로 열립니다.
- 모바일/PC에서 모두 볼 수 있는 **5단계 그림 안내**가 포함됩니다.
  1. 배송비 ON/OFF 및 할인율
  2. 수량 버튼 `−`, `+`, `+5`, `0`
  3. 카톡 주문 붙여넣기와 자동 인식
  4. 주문 총합계 확인
  5. 문구 형식 선택, 수정, 원터치 복사
- **도움말 안의 그림은 코드 내에 내장되어** 별도 이미지 파일 업로드가 필요 없습니다.
- 안내에는 기본 배송비 OFF, 주문 입력 간 합산, 계좌 `IM뱅크 508106077707 / 이서백`이 반영되어 있습니다.
- Streamlit의 기본 모달 팝업을 사용하여 모바일에서 설명서를 읽기 편하게 했습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub 적용

ZIP 압축을 풀고 `app.py`, `README.md`, `requirements.txt` 파일을 기존 GitHub 저장소에 업로드한 후 커밋하세요.

## 참고

- `app.py` 한 파일에 계산기와 사용설명서 그림이 모두 포함되어 있습니다.
- 고객 입력 데이터는 별도의 데이터베이스에 저장하지 않습니다.
- 입금계좌는 고정 안내 정보로 표시됩니다.
