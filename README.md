# 식혜 주문 자동계산기 PRO v13

## 기존 GitHub에 업로드
압축을 풀고 `app.py`, `requirements.txt`, `README.md` 세 파일을 GitHub 저장소의 최상위에 업로드하여 기존 파일을 덮어씁니다. `app_final.py`는 필요하지 않습니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## v13 개선
- 모바일 수량 카드 전체 너비 및 4버튼 글자 잘림 보정
- 총합계는 HTML 조각 출력 없이 Streamlit 컴포넌트만 사용
- 모바일 최종금액 상단, PC 최종금액 오른쪽 표시
- 배송비 받기 ON/OFF + 할인율을 메인 상단에 배치
- 기본 가격: 5000, 2950, 1550, 6700, 3950원
- 기본 계좌번호: 3333-29-8917220 / 이서백(식혜명가) (수정 가능)
- 카톡 주문 인식, 버튼 수량 합산, 문구 4종, 복사/TXT/CSV 유지
