# 식혜 주문 자동계산기 PRO

Streamlit으로 만든 식혜 주문 자동계산기입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 포함 기능

- 첫 화면 수량 버튼 계산기
  - `-`, `+`, `+5`, `0` 버튼
  - 직접 수량 입력 가능
  - 전체 수량 초기화 가능
- 카톡/문자 주문 붙여넣기 자동 인식
- 처음 입력창 예시는 placeholder라서 계산에 적용되지 않음
- 예시 문구 복사용 박스 제공
- 일반식혜 1L / 500ml / 200ml 파우치
- 단호박식혜 1L / 500ml
- 가격 수정 가능
- 할인율 적용
- 택배비 합산
- 입금계좌/예금주 입력
- 고객 발송 문구 3종 선택
  - 친절 기본형
  - 깔끔 영수증형
  - 입금 안내형
- 입금 안내형 문구에 계좌번호 자동 삽입
- 고객 문구 직접 수정 가능
- 계산 결과 CSV 다운로드
- 고객 문구 TXT 다운로드

## 오류 수정

수량 버튼 클릭 시 발생하던 `StreamlitAPIException`을 수정했습니다.  
위젯 상태를 직접 변경하지 않고 내부 수량 상태를 따로 관리하도록 바꿨습니다.
