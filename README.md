# 식혜 주문 자동계산기 PRO

식혜 주문을 빠르게 계산하는 Streamlit 웹앱입니다.

## 주요 기능

- 첫 화면 수량 버튼 계산기
- 상품별 + / - / +5 / 0 버튼
- 직접 수량 입력
- 카톡/문자 주문 붙여넣기 자동 인식
- 버튼 입력 + 붙여넣기 입력 합산 계산
- 일반식혜 1L / 500ml / 200ml 파우치
- 단호박식혜 1L / 500ml
- 할인율 적용
- 택배비 합산
- 계좌번호 / 예금주 입력
- 고객 발송 문구 3종 선택
- 입금 안내형 문구에 계좌 자동 삽입
- 고객 문구 직접 수정
- CSV / TXT 다운로드

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```
