# 식혜 주문 자동계산기 PRO v16

모바일과 PC 겸용. Streamlit 앱의 수량 버튼, 카톡 주문 인식, 상품 합계, 할인 및 배송, 고객 안내 문구 기능을 제공합니다.

## v16 변경 사항

- **입금 안내형**: 마지막의 '입금 후 성함 알려주시면 확인하겠습니다.'를 삭제하고 '감사합니다.'로 끝납니다.
- **깔끔 영수증형**: 하단에 `입금계좌: IM뱅크 508106077707`, `예금주: 이서백`, `감사합니다.`를 추가했습니다.
- **모바일 복사 버튼 및 나머지 기능**: v15와 동일합니다.

## v15부터 유지되는 기능

1. **택배비 받기 기본 OFF**: 처음 열 때 고객 배송비 0원 및 업체 부담 안내. 필요한 주문에서만 직접 ON으로 전환하세요.
2. **고객 안내 문구 원터치 복사**: 문구 입력칸 바로 아래 파란색 `📋 고객 안내 문구 바로 복사` 버튼. 누른 즉시 현재 수정한 문구를 클립보드로 복사합니다. 브라우저 권한이 막힌 경우 버튼 밑 대체 방법도 제공합니다.
3. **고정 입금정보**: IM뱅크 `508106077707`, 예금주 `이서백`. 입금 안내형 문구에서 자동으로 표시합니다.
4. v14의 모바일 UI, 빠른 부분 재실행, 수량 버튼, 할인 계산, 카톡 인식과 기본 가격은 유지합니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub 업로드

ZIP 압축을 풀고 저장소의 `app.py`, `README.md`, `requirements.txt` 파일을 같은 이름으로 교체한 뒤 커밋하세요.

## 유의사항

- 클립보드 사용 권한은 모바일 브라우저마다 다릅니다. HTTPS 접속 시 원터치 복사가 지원되는 경우가 많고, 보안 정책으로 차단될 경우 대체 복사 메뉴를 사용할 수 있습니다.
- 고객 안내 문구 수정 후에는 입력칸 밖을 눌러 변경을 적용하고 복사 버튼을 누르세요.
- 데이터는 별도 DB에 보관하지 않습니다.
