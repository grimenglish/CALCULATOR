# 식혜 주문 자동계산기 PRO v6

수량 버튼 계산기를 세로형 박스 UI로 바꾸고, 총합계는 오른쪽에 크게 보이도록 정리한 버전입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 포함 파일

- `app.py`
- `requirements.txt`
- `README.md`

## 주요 기능

- 왼쪽 세로형 수량 버튼 계산기
- 오른쪽 총합계 카드
- 카톡 주문 문구 자동 인식
- 일반식혜 1L / 500ml / 200ml 파우치
- 단호박식혜 1L / 500ml
- 상품 전체 할인율 적용
- 택배비 금액 설정
- 택배비 적용 ON/OFF 토글
- 입금계좌 / 예금주 입력
- 고객 발송 문구 3종 선택 및 수정
- 계산 결과 CSV 다운로드
- 고객 문구 TXT 다운로드
