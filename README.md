# 식혜 주문 자동계산기 PRO v8

상단 일러스트 SVG 코드가 화면에 그대로 표시되던 문제를 수정한 버전입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 수정 내용

- 상단 UI 일러스트를 순수 HTML/CSS 방식으로 변경
- SVG 코드가 화면에 그대로 출력되는 오류 제거
- `- / + / +5 / 0` 버튼 글자 크게 + 굵게 유지
- 택배비 OFF 시 `무료배송 안내형` 문구 유지
- 고객 문구에 `택배비 = 0원`, `택배비는 업체에서 부담합니다.` 자동 삽입
