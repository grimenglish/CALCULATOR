# 식혜 주문 자동계산기 PRO v5

카톡/문자 주문 문구와 버튼 수량을 함께 합산 계산하는 Streamlit 앱입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 포함 파일

- `app.py`
- `requirements.txt`
- `README.md`

## 주요 기능

- 수량 버튼 계산기
- 카톡 주문 문구 자동 인식
- 일반식혜 1L / 500ml / 200ml 파우치
- 단호박식혜 1L / 500ml
- 상품 전체 할인율 적용
- 택배비 금액 설정
- 택배비 적용 ON/OFF 토글
- 입금계좌 / 예금주 입력
- 고객 발송 문구 3종 선택 및 수정
- 계산 결과 CSV 다운로드
- 고객 문구 TXT 다운로드

## 인식 예시

```text
식혜 1L 3개
호박감주 500ml 2개
200x4
500 4개
새벽에 식혜 1L 4개랑 단호박식혜 500ML 1개줘
단호박식혜 / 호박감주 / 일반감주 / 감주 / 식혜 / 일반식혜
```
