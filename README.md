# 식혜 주문 자동계산기 PRO v12 (모바일 최적화)

Streamlit Cloud와 GitHub 배포용입니다.

## 설치·실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub 배포

압축을 풀고 `app.py`, `requirements.txt`, `README.md` 3개를 저장소 **최상위 폴더**에 업로드합니다. 기존 `app.py`는 이 파일로 덮어씁니다. Streamlit Cloud에서는 `app.py`를 실행 파일로 선택합니다. 앱에 이전 화면이 남으면 새로고침/재부팅합니다.

## 모바일에서 달라진 점

- 사이드바를 사용하지 않음. **택배비 받기 ON/OFF와 할인율을 맨 위에서 바로 변경** 가능
- 택배비 0원(업체 부담) 문구 자동 표기
- 상품 가격·계좌 수정은 메인 화면 `상품 가격 · 계좌 · 기본 용량 수정`에서 열기
- 모바일은 최종 결제금액이 수량 목록 위에 표시, PC는 수량 왼쪽/합계 오른쪽
- 버튼을 터치하기 쉬운 크기로 확대
- 기본가격: 5000 / 2950 / 1550 / 6700 / 3950원
- 기본계좌: 3333-29-8917220, 이서백(식혜명가)
- 고객문구 4종과 편집, TXT/CSV 저장

**계산 방법:** 상품 합계 - 상품 할인 + (택배비 받기 ON인 경우에만) 택배비. 주문이 없으면 최종금액 0원.

카톡 문구 분석은 정규식 기반이므로 모든 자연어 문장을 완벽하게 인식하지는 않습니다. 고객에게 전송 전 반드시 '주문 계산 내역'에서 품목·수량을 확인하세요.
