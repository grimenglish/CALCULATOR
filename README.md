# 식혜명가 주문 자동계산기 PRO v14

**목표:** 모바일 버튼 누름 지연과 화면 깨짐을 줄인 가벼운 Streamlit 계산기. GitHub/Streamlit Cloud에서 사용합니다.

## 업그레이드 핵심

- **부분 재실행**: `st.fragment`로 수량/배송/할인/고객 문구 계산만 다시 그려 전체 페이지 갱신을 줄였습니다.
- **모바일 우선**: 좁은 화면에서는 **최종 결제금액 → 주문 복붙 → 상품 수량 카드** 순서로 나타납니다. PC에서는 수량 카드를 왼쪽, 금액과 복붙 입력창을 오른쪽에 배치합니다.
- **안전한 화면**: 총합계는 Streamlit 기본 컴포넌트로만 표시해 HTML 코드가 문자로 출력되는 오류를 막습니다.
- **간결한 계산 엔진**: `pandas` 제거. 주문/금액 계산은 Python 기본 기능으로 처리합니다.
- **빠른 버튼**: −, +, +5, 0 / 직접 수량 변경 / 전체 수량 초기화.
- **정확한 결제액**: 상품 금액에만 할인, 배송비는 별도 합산. 배송비 OFF 시 고객 문구에 '택배비 0원 / 업체 부담' 표시. 주문이 0개면 배송비도 0원입니다.
- **주문 인식**: 식혜/감주/일반감주/단호박식혜/호박감주/띄어쓰기/200x4 등.
- **고객 문구 4종**: 친절 기본형, 영수증형, 입금 안내형, 배송비 안내형. 직접 수정 가능. 할인율 0일 때 할인 문구 숨김.

## 설치 및 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

### GitHub에 올릴 파일

압축을 푼 다음 아래 **세 파일만** 기존 GitHub 저장소의 파일과 교체하면 됩니다.

```text
app.py
requirements.txt
README.md
```

`app_final.py` 같은 이름의 다른 진입 파일은 사용하지 않습니다.

- 주문 인식 19가지 자동 회귀 검사
