# 식혜 주문 자동계산기

카톡/문자 주문을 붙여넣으면 식혜 주문 금액을 자동 계산하는 Streamlit 앱입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 기본 상품

- 일반식혜 1L
- 일반식혜 500ml
- 단호박식혜 1L
- 단호박식혜 500ml

가격은 앱 왼쪽 사이드바에서 수정할 수 있습니다.

## 예시 입력

```text
식혜 1L 3개
호박 감주 1L 2개
식혜 500ml 5개
단호박식혜 500ml 4개
```
